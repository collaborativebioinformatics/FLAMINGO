# Introduction

Large biobanks make it possible to study the determinants of disease at scale, but the most informative analyses often need data held by several institutions. Privacy law (e.g. GDPR), consent terms and data-access agreements usually prevent individual-level records from being shared between sites. Federated learning (FL) addresses this by leaving the data where it is. Each site (node) trains a model on its own data and shares only model parameters or gradients with a central server. The server combines these into a global model and sends it back to the nodes for the next round of training, and the cycle repeats until the global model converges.

Mendelian randomization (MR) runs into the same constraint but has largely solved it without FL. The standard MR estimators (inverse-variance weighted (IVW), MR-Egger, weighted median) need only the per-variant effect estimates and standard errors for the exposure and the outcome, and these summary statistics are routinely shared. For linear models, fixed-effects meta-analysis of per-site estimates is asymptotically as efficient as pooling the individual-level data. This argument holds only for linear, additive models. Some analyses need individual-level data and cannot be rebuilt from standard summary statistics: non-linear MR, which estimates how the causal effect changes across the range of the exposure; tests of gene–environment interaction; and consistent covariate adjustment across sites. For these analyses, FL is a legitimate alternative to pooling data. Here we test whether a federated two-stage MR model can recover a non-linear causal dose–response curve across biobanks that cannot share data, and compare it with summary-statistic MR and with a fit on the pooled individual-level data.

# Methods

We simulated ten biobank sites that share one causal model. At each site, 20 independent SNPs affect a continuous exposure X, and an unmeasured confounder U affects both X and the outcome Y. The causal effect of X on Y was identical at every site. The main scenario was quadratic, f(X) = θ1·X + θ2·X² with θ1 = 0.30 and θ2 = 0.15, and we repeated the analysis with linear, threshold and Cox survival outcomes. To mimic biobanks in different countries, the nuisance parameters varied between sites: sample size was drawn across 1,000–10,000 (one draw per equal-width bin), the SNP heritability of X from a Beta distribution with mean 0.10, and the confounder effects on X and Y from independent Beta distributions with mean 0.30. Each site used its own random seed, so allele frequencies, per-SNP effects and individuals all differed between sites. The SNPs had no direct effect on Y (no pleiotropy) and were not in linkage disequilibrium.

We estimated the causal effect in three ways. (i) Summary statistics: each site ran a GWAS of X and of Y in the same individuals and computed a per-site IVW estimate, and the ten estimates were combined by inverse-variance meta-analysis, with Cochran's Q to measure heterogeneity. Because the SNPs differ between sites, only the per-site causal estimates were meta-analysed, never the per-SNP effects. (ii) Concatenated: as a reference, all individual-level data were pooled and fitted by two-stage least squares, with X and X² instrumented by the SNP-predicted exposure from a per-site first stage and its square, and with site intercepts. (iii) Federated: we ran FedAvg in NVFlare 2.9 with one client per site. Each site split its data 80/20 into training and test sets and fitted its own first stage, an ordinary least-squares regression of X on its SNPs, which never left the site. Only the second stage was federated, as a control-function (two-stage residual inclusion) model Y = f(X) + c·(X − X̂), where f is a multilayer perceptron (two hidden layers of 32 ReLU units) that represents the causal curve and the linear first-stage residual term carries the confounding. In each of five rounds, every client trained for two epochs (Adam, learning rate 0.01, batch size 256) and the server averaged the weights, weighted by training-set size. A naive federated model, Y = f(X) with no instruments, gave the confounded association for comparison. The final global f was compared with the true causal curve and with the curves from routes (i) and (ii).
