# Introduction

Bio-banks make it possible to study the determinants of disease at scale, but the most informative analyses often need individual-level data is usually restrained by privacy concerns. Federated learning (FL) works around this by keeping the data in place: trains a model locally at each cite and shares only model parameters or gradients with a central server, which combines them into a global model and sends it back for further rounds of training until it converges. Mendelian randomization (MR) is a statistical method aims to test a causal hypothesis on non-experimental data. MR runs into the same constraint but has largely solved it without FL. The standard MR estimators (inverse-variance weighted (IVW), MR-Egger, weighted median) only need the per-variant effect estimates and standard errors for the exposure and the outcome, and these summary statistics are routinely shared. For linear models, fixed-effects meta-analysis of per-site estimates is as efficient as pooling the individual-level data. This argument holds only for linear, additive models. Non-linear MR needs individual-level data and cannot be rebuilt from standard summary statistics. It estimates how the causal effect changes across the range of the exposure, tests of gene–environment interaction, and consistently adjusts covariates across sites. For these analyses, FL is a legitimate alternative to pooling data. Here we test whether a federated two-stage MR model can recover a non-linear causal dose–response curve across bio-banks that cannot share data, and compare it with summary-statistic MR and with a fit on the pooled individual-level data.

# Methods

We simulated ten bio-bank sites that share one causal model. At each site, 20 independent SNPs affect a continuous exposure X, and an unmeasured confounder U affects both X and the outcome Y. The causal effect of X on Y was identical across all site. Site-specific causal effects were estimated using inverse-variance weighted (IVW) MR and subsequently combined using inverse-variance meta-analysis. For nonlinear analyses, quadratic two-stage least squares (2SLS) models were additionally fitted locally and combined using multivariate inverse-variance meta-analysis. As an individual-level reference, data from all biobanks were concatenated and analyzed using pooled 2SLS with site-specific first-stage models and site intercepts. To mimic bio-banks in different countries, the nuisance parameters varied between sites: sample size varied between across 1,000–10,000. Each site used its own random seed, so the individuals, the minor allele frequencies (drawn from U(0.05, 0.5)) and the per-SNP effects (drawn from a normal distribution and rescaled to the site's heritability) all differed between sites. linkage disequilibrium and horizontal pleiotropy were not simulated.

For conventional MR, SNP–exposure and SNP–outcome associations were estimated separately within each bio-bank. Site-specific causal effects were estimated using inverse-variance weighted (IVW) MR and subsequently combined using inverse-variance meta-analysis. For nonlinear analyses, quadratic two-stage least squares (2SLS) models were additionally fitted locally and combined using multivariate inverse-variance meta-analysis. As an individual-level reference, data from all biobanks were concatenated and analyzed using pooled 2SLS with site-specific first-stage models and site intercepts.

Federated MR was implemented using NVIDIA FLARE with federated averaging. Within each biobank, the first-stage regression of the exposure on the genetic variants was fitted locally. The default two-stage residual inclusion (2SRI) model then federated the second-stage model, defined as Y=f(X)+c(X−X^)Y=f(X)+c(X-\hat{X}), where f(X)f(X) was represented by a multilayer perceptron and the first-stage residual acted as a control function. Only model parameters were exchanged between sites; individual-level genotype, exposure, and outcome data remained local. Two-stage predictor substitution (2SPS) and a naive federated exposure–outcome model were also implemented as alternative analyses.
